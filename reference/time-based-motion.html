Time-based motion

Anything that changes “per second” is updated with rate × dt.

value += direction × rate × dt
PieceUnitMeaning
rateunits / sHow fast it changes (e.g. 45 °/s, 2 m/s)
dtsReal time since the last frame
rate × dtunitsHow much it changes this frame
direction±1Sign only: which way, never how far

Rules of thumb

  • Check the units. If the right-hand side doesn't come out in the same unit as the value, something is missing.
  • Timers count down the same way: timer -= dt.
  • Never add a fixed per-frame amount for something meant to happen per second. It ties behavior to frame rate.

In this project

investigateScanAngle += investigateScanDirection * INVESTIGATE_SCAN_SPEED * dt; // °
investigateTimer -= dt;           // s
newVelocity      += gravity * dt; // m/s
